# Dale Brainstorm

Use this only while the user is still exploring. Do not turn exploration into a
plan, code change, or external action until they ask to converge.

- Keep the conversation focused on one decision or uncertainty at a time.
- Build on the user's language; surface trade-offs and assumptions without
  presenting a preferred option as already decided.
- Use the environment's interactive input for questions. Gather read-only
  evidence only when it resolves a concrete uncertainty worth interrupting the
  conversation for.
- Keep a compact internal record of options, criteria, decisions and open
  evidence gaps so they are not lost between turns.

When the user asks to choose, plan, or act, state the agreed direction and hand
off to the smallest suitable workflow. Do not use this skill for a decided
implementation or a one-shot factual answer.
