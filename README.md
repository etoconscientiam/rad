# RAKURS furniture — сайт мастерской стальной мебели

E-commerce для мастерской стальной мебели (Тбилиси). Ключевая фича — **визуальный конструктор**
изделия с живой 3D-моделью и мгновенным расчётом цены.

## Статус

Этап изучения исходников. Кода приложения ещё нет — сначала пайплан.

## Структура

```
docs/                     — аналитика и спецификации
  01-audit-prototype.md   — что в архиве прототипа и что из этого годится
  02-domain-model.md      — модели, размеры, формулы цены, сроки, статусы
  03-assets.md            — инвентарь ассетов
_source/                  — ИСХОДНИКИ, НЕ РЕДАКТИРОВАТЬ
  prototype/              — распакованный прототип Claude Design
  Прототип конфигуратора с 3D.zip (не в git)
tools/
  serve-prototype.sh      — поднять прототип локально на :8777
CLAUDE.md                 — правила работы в этом репозитории
```

## Посмотреть прототип

```bash
./tools/serve-prototype.sh
# → http://localhost:8777/STAL%20Prototype.dc.html
```
