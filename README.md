# RAKURS furniture — сайт мастерской стальной мебели

E-commerce для мастерской стальной мебели (Тбилиси). Ключевая фича — **визуальный конструктор**
изделия с живой 3D-моделью и мгновенным расчётом цены.

## Статус

Этап изучения исходников. Кода приложения ещё нет — сначала пайплан.

Стек зафиксирован владельцем 06.09.2026 (подробности и обоснования — в `docs/04-repo-review.md`):
**Next.js + TypeScript, Tailwind + shadcn/ui, Three.js через react-three-fiber,
Supabase, Vercel, next-intl, Vitest + Playwright.** Оплата — сменный модуль
(эквайринг банка Грузии + крипта), Stripe в регионе недоступен.
