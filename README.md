# RAKURS furniture — сайт мастерской стальной мебели

E-commerce для мастерской стальной мебели (Тбилиси). Ключевая фича — **визуальный конструктор**
изделия с живой 3D-моделью и мгновенным расчётом цены.

## Статус

Спринт до 24.09.2026 — закрытый показ конфигуратора (Cube и Deska), заявка в Todoist,
два языка ka/ru. Объём и границы — `docs/handoff-prompt.md`.

Собран каркас: Next.js 15 + TypeScript, Tailwind v4 на токенах ДС «Каркас»,
локальные шрифты, next-intl (ka по умолчанию, ru), четыре компонента дизайн-системы.

Стек зафиксирован владельцем 06.09.2026 (подробности и обоснования — в `docs/04-repo-review.md`):
**Next.js + TypeScript, Tailwind + shadcn/ui, Three.js через react-three-fiber,
Supabase, Vercel, next-intl, Vitest + Playwright.** Оплата — сменный модуль
(эквайринг банка Грузии + крипта), Stripe в регионе недоступен.

## Запуск

```
npm install
npm run dev     # http://localhost:3000/ka — грузинский, /ru — русский
npm run check   # typecheck + lint + тесты
npm run build
```

Витрина компонентов дизайн-системы для визуальной сверки с прототипом — `/ka/ui`, `/ru/ui`.
Страница рабочая, в продакшен не идёт.

## Посмотреть прототип

```bash
./tools/serve-prototype.sh
# → http://localhost:8777/STAL%20Prototype.dc.html
```

## Пайплайн

```bash
open docs/pipeline.html
```

Три фазы: **Фундамент** (3–5 дней) → **MVP** (~5–7 недель, ключевой этап) → **Полная версия**.
Внутри — интерактивная диаграмма Ганта: 75 рабочих вечеров, связи между задачами,
критический путь, внешние ожидания (ответы владельца, фото, переговоры с банком).
Граница MVP проведена по прототипу: всё, что Claude Design показал на экране, работает
по-настоящему. Формальная приёмка — чек-лист паритета из 21 пункта. Отметки в странице
сохраняются в браузере.
