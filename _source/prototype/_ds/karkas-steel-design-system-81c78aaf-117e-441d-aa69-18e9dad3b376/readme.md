# Каркас (Karkas) — дизайн-система

Сайт кастомной стальной мебели с 3D-конфигуратором каркасов (Тбилиси). Характер бренда: **индустриальный минимализм** — точность, металл, мастерская. Современно, сдержанно, без декоративного шума.

> «Каркас / Karkas» — рабочее имя: бренд-нейм в исходных материалах не указан. Логотип не предоставлен — везде вместо знака набирается имя бренда обычным текстом (Manrope 800). Не рисовать логотип.

**Источник:** текстовое ТЗ/бренд-спецификация, переданная в чате (июль 2026). Кодбейз и Figma не предоставлялись — компоненты авторские, строго по спецификации.

**Продукты:**
1. **Сайт** — маркетинговая главная + 3D-конфигуратор (размеры, сечение профиля, цвет) + трекинг заказа. Mobile-first.
2. **Админка** — таблица заказов, статусы. Светлая, с тёмным сайдбаром.

## Принципы
- Приглушённая нейтральная база, один акцент — красный `--accent`. Красный = «действие»: один основной красный элемент на экран-зону. Никогда — большие заливки, фоны секций, длинный текст.
- Плоский дизайн: без градиентов, глубоких теней, стекла. Глубина — бордерами и слоями фона.
- 3D-модель — герой. UI вокруг нейтральный, чтобы цвета изделия (чёрный/серый/белый) читались честно.
- Числа — часть эстетики: размеры, цены, статусы — моноширинным (JetBrains Mono), как маркировка на металле.
- Тач-зоны ≥ 44px; слайдеры дублируются числовым вводом.

## CONTENT FUNDAMENTALS
- Язык: русский. Валюта: лари, знак «₾» после суммы через « · » в кнопках: «Заказать · 420 ₾».
- Sentence case везде; БЕЗ капса в заголовках. Капс только в микролейблах 11px +8% tracking: «ВЫСОТА, ММ».
- Тон: мастерская, а не магазин. Коротко, предметно, технически честно: «Порошковая покраска. Сталь 2 мм». Без восклицаний, без маркетинговых суперлативов, без эмодзи.
- Обращение на «вы» (строчная), императив в CTA: «Заказать», «Собрать свой».
- Числа и единицы: мм, кг, ₾ — всегда mono. Разделитель размеров «×» (1200×600×450).
- Статус = цвет + текст, красный никогда не единственный носитель смысла.

## VISUAL FOUNDATIONS
- **Цвет:** тёплые серо-бежевые нейтральные (не голубые). Светлая тема — основная. Тёмные зоны `--graphite` #26251F: hero, футер, сайдбар админки (текст #F4F3F0, вторичный #A5A29A, красный на тёмном — #D4483A). Семантика: success #4A7C59, warning #B98A2F, danger = accent (намеренно).
- **Тип:** Manrope (UI, cyrillic) + JetBrains Mono (числа). Display 44–64/1.05/800/-2%; H1 32/700; H2 24/700; H3 18/600; Body 16/1.55; Small 13. Цена 28 mono 600 `--accent`; параметры 15 mono 500.
- **Сетка:** база 4px; шаги 8/12/16/24/32/48/64. Контейнер 1200px, гаттер 24 (моб. 16).
- **Форма:** радиусы 8 (контролы), 12 (карточки), 999 (чипы/свотчи). Без пилюльных кнопок. Бордеры 1px; активное — 2px `--accent`.
- **Тени:** почти нет. Единственная — sticky-панель заказа: `--shadow-sticky`.
- **Фоны:** плоские заливки токенами; никаких градиентов, текстур, паттернов, blur/стекла. Фото — без рамок, прямо в карточке 12px.
- **Анимации:** сдержанные, 150–200ms ease-out: цвет/бордер на hover, лёгкий fade размерных линий в 3D. Без bounce и параллаксов.
- **Hover:** кнопки primary → `--accent-hover`; secondary/ghost → фон `--surface-sunken`; строки таблиц → `--surface-sunken`; бордеры → `--border-strong`.
- **Press:** чуть темнее hover; без scale-эффектов.
- **Фокус:** 2px `--accent` outline, offset 2px.
- **3D-вьюпорт:** фон `--surface-sunken`, мягкая виньетка допустима, тень-контакт у пола. Нейтральный студийный свет. Размерные линии 1px `--ink-secondary` с моно-подписями «1200 мм», появляются при изменении и гаснут. Контролы — ghost-иконки 40px в углу.
- **Фото:** нейтральный фон или реальные интерьеры, естественный свет, без фильтров и стоковых людей.

## ICONOGRAPHY
- Линейные иконки **Lucide**, stroke 1.5px, из CDN (lucide-static, через CSS-mask в компоненте `Icon`). Своих SVG не рисовать.
- Эмодзи не используются. Из юникода допустимы только «×» в размерах, «·» в кнопках c ценой, «→» в ссылках.
- Логотипа нет (не предоставлен) — имя бренда plain-type.

## Индекс
- `styles.css` → `tokens/` (fonts, colors, typography, spacing, base)
- `guidelines/` — карточки-спецификации (Colors / Type / Spacing / Brand)
- `components/buttons/` — Button, IconButton
- `components/forms/` — Input, SizeSlider, SegmentControl, ColorSwatches
- `components/display/` — Card, StatusChip, Price
- `components/feedback/` — Toast, OrderTimeline
- `components/admin/` — OrdersTable
- `components/icons/` — Icon (Lucide via CDN)
- `ui_kits/site/` — конфигуратор (index.html), главная (home.html), трекинг (tracking.html)
- `ui_kits/admin/` — заказы (index.html)
- `SKILL.md` — точка входа для агентов

### Intentional additions
- `Icon` — обёртка над Lucide CDN (нужен единый способ рендерить линейные иконки 1.5px).
- `Price` — типографическая роль «цена» из спецификации, оформлена компонентом.

### Каверзы
- Шрифты подключены с Google Fonts CDN (Manrope, JetBrains Mono — именно те, что в ТЗ; локальных бинарников нет). Для оффлайна — положить woff2 в `assets/fonts/` и переписать `tokens/fonts.css` на @font-face.
