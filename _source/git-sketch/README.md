# RAKURS furniture

> New way how to buy simple furniture.

Мастерская стальной мебели, Тбилиси. Сайт с 3D-конфигуратором каркасов,
приёмом заказа, админкой и печатью нарядов подрядчикам.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `design/` | Текущая выгрузка из Claude Design. Всегда только последняя. |
| `docs/` | Начинать с `docs/project.md`: что строим, стек, этапы, правила. Рядом `process.md` про бизнес-процесс. |
| `_inbox/` | Сюда кладём новые zip из Claude Design. В историю не попадает. |
| `app/` | Рабочее приложение: сейчас — форма заказа + приём в Todoist. Деплоится на Vercel. |

## Как работать с версиями

Прошлые версии **не хранятся папками** — их держит сама история git.
Чтобы посмотреть, что было раньше, не нужно искать `design-v1`, `design-v2-final`:

```
git log --oneline        # список всех версий
git show <номер>         # что именно изменилось
```

## Порядок при новой версии дизайна

1. В Claude Design выгружаете проект (Export / Download) — получается zip.
2. Кладёте zip в папку `_inbox/`.
3. Говорите мне: «положил новую версию».
4. Я распаковываю в `design/`, смотрю, что изменилось относительно прошлой,
   и делаю коммит с понятным описанием.

Так параллельная работа в Claude Design и здесь остаётся согласованной:
каждая ваша итерация дизайна становится точкой в истории проекта.

## Правила

- Секреты (ключи, пароли, токены) — только в `.env`, в git не попадают никогда.
- Каждая заметная работа — отдельный коммит с понятным описанием по-русски.
- Ветка `main` — то, что считается актуальным.
