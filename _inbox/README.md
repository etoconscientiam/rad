# _inbox

Сюда кладутся **новые выгрузки из Claude Design** (zip) и другие материалы от заказчика.

Порядок:

1. Экспортируете проект в Claude Design → получается zip.
2. Кладёте zip в эту папку.
3. Говорите: «положил новую версию».
4. Я распаковываю в `_source/prototype/`, сверяю, что изменилось относительно текущей,
   и делаю коммит с описанием изменений.

Сами файлы в git не попадают — в историю едет только распакованный результат в `_source/`.
Альтернатива ручной передаче — инструмент DesignSync, он тянет файлы из Claude Design напрямую.

Конвенция унаследована из вашего наброска `Rakurs_furniture` и восстановлена здесь.
