# Шрифты

Переменные начертания woff2, скачаны из Google Fonts. Суммарно ~274 КБ на 16 файлов,
разбитых по подмножествам — браузер грузит только нужные диапазоны символов.

| Семейство | Роль | Подмножества |
|---|---|---|
| **Onest** | UI-шрифт в прототипе | latin, latin-ext, cyrillic, cyrillic-ext |
| **Manrope** | UI-шрифт по бренд-спеке | latin, latin-ext, cyrillic, cyrillic-ext |
| **JetBrains Mono** | числа, размеры, цены, номера заказов | latin, latin-ext, cyrillic, cyrillic-ext |
| **Noto Sans Georgian** | грузинский текст | georgian, latin, latin-ext |

Оба кандидата на UI-шрифт скачаны намеренно: выбор между Manrope (бренд-спека) и Onest (прототип)
отложен, это открытый вопрос трека 0.1. После решения лишнее семейство удалить.

- `fonts.css` — готовые `@font-face` с корректными `unicode-range`. Эталон подмножеств.
- `faces.json` — машинночитаемое описание, откуда сгенерирован CSS.

В Next.js подключать через `next/font/local` — он сам проставит `font-display`, preload
и сгенерирует стабильные имена классов. `fonts.css` в этом случае служит справкой
по диапазонам символов, а не подключается напрямую.

**Не подключать шрифты с Google Fonts CDN** — так сделано в прототипе, для продакшена это
лишний внешний запрос в критическом пути рендера.
