**Апгрейд мажоров — первая задача после показа**, до начала M2.

### Почему react понижен до 19.2.8

`@react-three/fiber@9.7.0` объявляет peer `react: >=19 <19.3`, а первоначально
встал `react@19.3.0`. Без понижения npm пытается разрешить опциональный peer `expo`
и тянет в граф весь React Native. Понижение до 19.2.8 — минимальное решение:
Next 15.5 заявляет peer `react: ^19.0.0` и с 19.2.8 работает штатно, сборка и 88 тестов
зелёные. Ограничение сверху идёт от r3f, а не от Next.

**Следствие для апгрейда:** поднимать Next до 16 и react до 19.3+ можно только вместе
с версией r3f, которая снимет верхнюю границу. Проверять эту связку до, а не после.

## Бизнес-процесс (из `process.md`)

Конфигуратор → корзина → оплата → заказ в админке → **печать двух раздельных нарядов**
(сварщикам: метраж профиля, сечение, размеры, покраска; ЛДСПшникам: площадь, цвет, раскрой)
→ мастер ведёт статусы → клиент получает оповещение.

Роли: клиент, мастер (владелец), сварщики и ЛДСПшники (в систему **не заходят**, получают бумагу).
Рынки: Грузия, затем Армения. Дальняя цель — сеть мастерских в разных странах, решения тиражируемые.
