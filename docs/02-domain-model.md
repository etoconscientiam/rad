# Предметная модель, извлечённая из прототипа

Всё ниже — фактические значения из `_source/prototype/STAL Prototype.dc.html` (строки ~530–630).
Это спецификация «как есть в прототипе», а **не** утверждённый прайс. Требует подтверждения заказчиком.

## Бренд

- Названия: `ka: რაკურსი`, `en: RAKURS`, `ru: Ракурс`. Логотипа нет — только текст (Manrope 800).
- Мастерская стальной мебели, Тбилиси. Адрес: ул. Бахтриони 5, пн–сб 10:00–19:00.
- Валюта: лари `₾`.

## Модели изделий

| Код | Название | Что это | Высота (мм) | Ширина (мм) | Длина (мм) |
|---|---|---|---|---|---|
| `cube` | Cube | голый каркас-параллелепипед | 200–2000 | 200–2000 | 200–2000 |
| `deska` | Deska | стол: 4 ноги + царги + столешница ЛДСП | 400–1100 | 500–1000 | 800–2200 |
| `pats` | Pats | как Deska + замкнутые боковые рамы | 400–1100 | 500–1000 | 800–2200 |
| `chestable` | Chestable | Pats + тумба на 2 ящика (каркас 15×15 + ЛДСП) | 600–1100 | 500–1000 | 800–2200 |
| `stella` | Stella | стеллаж: 5 полок ЛДСП | высота считается | 250–500 (глубина) | 600–1400 (ширина) |

Дефолты: `cube 750×450×1200 / 30×30`, столы `730×600×1400 / 20×20`, `stella` шаг полок 300 мм, `350×900`.
Для `stella` высота = `5 × (профиль + 20) + 4 × шаг_полок`, шаг регулируется 280–350 мм.
У `chestable` — расширение ящика 0–200 мм.

## Профиль и тарифы

| Сечение | ₾ за метр | кг за метр |
|---|---|---|
| 20×20 | 18 | 0.9 |
| 30×30 | 26 | 1.4 |
| 40×40 | 36 | 2.0 |

- ЛДСП: **55 ₾/м²**, вес **11.7 кг/м²**.
- Покраска: **+40 ₾**, работа: **+60 ₾** — включены в цену каждой позиции.
- Предупреждение: если профиль 20×20 и любой габарит > 1500 мм — рекомендуем 30×30.

## Формулы цены (по коду прототипа)

**Cube:** `метраж = 4 × (h + w + l) / 1000` → `цена = round(метраж × ставка + 40 + 60)`

**Столы (deska / pats / chestable):**
```
метраж = (4×h + 2×(w + l) + (модель ≠ deska ? 2×w : 0)) / 1000
площадь = w × l / 1e6
цена    = round(метраж × ставка + площадь × 55 + 40 + 60) + цена_ящика
```
Ящик (только `chestable`): `cw = max(w/1000 × 0.7, 0.3)`, `cd = 0.45 + расширение/1000`,
`каркас = 4×0.41 + 2×(cw + cd)`, `лдсп = 2×0.4×(cw + cd) + cw×cd`,
`цена_ящика = round(каркас × 14 + лдсп × 55 + 25)`.

**Stella:** `H = 5×(профиль + 20) + 4×шаг`, `метраж = (4×H + 10×(w + l)) / 1000`,
`площадь = 5 × w × l / 1e6`, `цена = round(метраж × ставка + площадь × 55 + 40 + 60)`.

**Вес:** `метраж × кг_за_метр + площадь × 11.7` (+ вес ящика).

## Доставка

Базовый тариф **30 ₾** (проп `deliveryFee`), далее по количеству в корзине:
`> 3 шт: +20`, `> 10 шт: +30`, `> 50 шт: +40` — итого 30 / 50 / 80 / 120 ₾.
Альтернатива — самовывоз (0 ₾).

## Сроки изготовления

| Количество | Срок |
|---|---|
| ≤ 5 шт | 7–10 дней |
| ≤ 20 шт | 9–13 дней |
| > 20 шт | 14–17 дней |

## Отделка

- Цвет металла: `black #17171A`, `gray #8E9094`, `white #F2F1EE`.
- ЛДСП: `light` (орех), `grey` (серый дуб), `dark` (тёмный дуб), `white` — с текстурами.

## Статусы заказа

`Заказ получен → В производстве → Готов → Доставка → Завершён`
(коды: `received / production / ready / delivery / done`).

## Оформление заказа

Поля: имя, **телефон (обязателен)**, email, способ получения (самовывоз / доставка по Тбилиси),
адрес, комментарий. Оплата — редирект в банк (в прототипе имитация 1.5 с + демо-флаг ошибки).
После оплаты: номер заказа, ссылка на трекинг, предложение статусов в Telegram.
