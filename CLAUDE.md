# Правила работы в репозитории RAKURS

## Язык
Общение и документация — по-русски. UI сайта трёхъязычный: ka / en / ru (грузинский — по умолчанию).

## Неприкосновенное
- `_source/**` — исходные материалы заказчика (архив прототипа Claude Design).
  **Только чтение.** Ничего туда не дописывать и не править: это референс и доказательная база.
- Дизайн-токены из `_source/prototype/_ds/.../tokens/*.css` переносятся в проект **без изменений значений**.
  Новые цвета/размеры не выдумывать — если чего-то не хватает, сначала спросить.

## Дизайн-правила (из бренд-спеки, `_source/prototype/_ds/.../readme.md`)
- Индустриальный минимализм: плоско, без градиентов, стекла, теней (единственная тень — sticky-панель).
- Один красный акцент `--accent` на экран-зону. Красный = действие, не фон.
- Числа (размеры, цены, статусы) — моноширинным шрифтом.
- Sentence case, без капса в заголовках. Капс — только микролейблы 11px.
- Тач-зоны ≥ 44px, слайдеры всегда дублируются числовым вводом.
- Иконки — только Lucide, stroke 1.5px. Эмодзи не использовать.
- Тон текстов: мастерская, не магазин. Технически честно, без суперлативов.

## Деньги
Расчёт цены, продублированный на клиенте, **обязан** проверяться на сервере при создании заказа.
Тарифы и формулы (см. `docs/02-domain-model.md`) не хардкодить в компонентах — выносить в конфиг/БД.

## Рабочий процесс
- Прежде чем менять принятые формулы цен, сроки или размерные диапазоны — согласовать с заказчиком.
- Перед крупными изменениями структуры — план, потом код.
